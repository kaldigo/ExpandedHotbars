# Hotbar icon override credits

These replacement renderings were generated with the built-in image generator from the existing plugin icon plus a native FFXIV utility/menu-icon style reference with quiet background colours shared by artwork family. They are fan-made hotbar artwork, not official replacement branding. Original plugin names, marks and reference artwork belong to their respective creators. The game reference sheet was extracted locally for style guidance and is not bundled.

Stylist uses a generated utility-style interpretation of the [Kaldigo fork character emblem](https://raw.githubusercontent.com/kaldigo/Stylist/main/assets/icon.png), preserving its swept hair, ponytail and angular collar in the Kaldigo cyan/magenta palette on shared indigo. Source: [kaldigo/Stylist](https://github.com/kaldigo/Stylist), based on [NightmareXIV/Stylist](https://github.com/NightmareXIV/Stylist). The visible question-mark fallback remains original generated artwork.

Steward uses an original inventory/checkmark utility emblem in the Kaldigo palette, with the [companion icon](https://raw.githubusercontent.com/kaldigo/FFXIVSteward/main/assets/icon.png) as a palette reference. Plugin: [kaldigo/FFXIVSteward](https://github.com/kaldigo/FFXIVSteward). AutoRetainer now uses the recoloured Kaldigo fork emblem; the original upstream attribution and license remain retained. Both share the Kaldigo indigo background.

Item Search uses a generated utility-style interpretation of its [original magnifying-glass icon](https://raw.githubusercontent.com/Caraxi/ItemSearchPlugin/master/icon.png), with a blue lens, silver rim and quiet slate-blue background. Source: [Caraxi/ItemSearchPlugin](https://github.com/Caraxi/ItemSearchPlugin), by Caraxi and maintained by Khayle. The source repository's Affero General Public License, version 1, is retained verbatim in `licenses/ItemSearchPlugin.txt`.
